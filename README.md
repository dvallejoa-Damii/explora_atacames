# 🌊 Explora Atacames - Sitio Web de Turismo

## Información General
- **Nombre del proyecto:** Explora Atacames — Sitio Web de Agencia de Turismo
- **Estudiante:** DAMARIS LISET VALLEJO ANCHUNDIA
- **Destino turístico asignado:** Atacames, Provincia de Esmeraldas, Ecuador
- **Enfoque:** Playa, gastronomía, actividades acuáticas y recreación

## Descripción del Proyecto
Sitio web completo desarrollado como trabajo final de la asignatura. Presenta información turística real e investigada sobre el cantón Atacames: sus atractivos, playas principales, servicios y paquetes turísticos, información institucional de la agencia y formulario de contacto y reservas. El sitio es funcional, responsivo y se adapta a cualquier dispositivo.

## ✅ Contenido Investigado
- **6 Atractivos turísticos:** Playa Principal, Malecón, Tonsupa, Súa, Tonchigüe, Avistamiento de Ballenas
- **Gastronomía:** Encocado, ceviche, bolón de verde, tapao, empanadas
- **Actividades:** Surf, snorkeling, paseos en bote, avistamiento de ballenas (junio–septiembre)
- **Hospedaje:** Hoteles, cabañas, condominios en Atacames y parroquias
- **Cultura:** Herencia afro-ecuatoriana, marimba, tradiciones y clima
